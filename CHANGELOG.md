# Changelog

Changes describe the source version; they do not imply a published package or release tag.

## 0.1.0 — Initial source version

### Added

- Local raster import, original sample artwork and text-to-image creation.
- Measured right-angle floor/wall projection with an explicit viewing point.
- True inverse rasterization, shrinking auto-fit, sampled clipping estimates and bounded effective DPI.
- Disposable Three.js camera/orbit preview with usable 2D/print fallback when WebGL is unavailable.
- Version 1 project save/open and separate warped floor/wall PNG downloads.
- Self-contained A4 assembly plans with numbered tiles, placement diagram and calibration rulers.
- Geometry, validation and browser regression checks, English documentation and contribution guidance.

### Boundaries

Physical printer/lens calibration, room scanning, arbitrary surface geometry and live camera capture are outside this version.
